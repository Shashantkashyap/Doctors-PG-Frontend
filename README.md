# Doctors-PG-Frontend-

High-yield medical revision and clinical micro-drill frontend for NEET PG, INI-CET, and FMGE aspirants.

## Features
- **3-Layer Revision Architecture**: 
  - **90s Clinical Card**: Golden Anchors (DOC, IOC, MCC), Numerical Cutoffs, Differential Comparison (Twins Matrix), Protocols & Regimens, and Exam Traps.
  - **5m Checklist**: Interactive clinical domains with item check-off and live progress tracking.
  - **10 MCQs Micro-Drill**: Rapid assessment with 4-option clinical rule-out rationales.
- **Apple iOS / Linear Design System**: Inset grouped cards, sticky non-blocking navigation, fluid segmented switcher, and clean medical typography.
- **Strict Authentication**: JWT Bearer auth integration with profile management and cloud sync.
- **PWA & Offline Support**: Service worker caching with Workbox.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide React
- Axios
